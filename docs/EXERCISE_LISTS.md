# Exercise lists

Entrenamiento separates direct applications of a taught idea (exercises) from tasks requiring a less immediate choice or combination of ideas (problems). This is an editorial judgment, not a difficulty or competition-source filter. A short proof can be an exercise when it directly practices a proof method; a numerical answer can still require problem solving.

The registry in `server/src/data/exerciseLists.js` starts with the exercise boxes in each rewritten lesson. Its `additional` entries record direct applications that appeared in other boxes or in the original bank. For example, TP-G23 is a direct similarity calculation and TP-A03 applies an identity, so they are exercises even though they appeared as practice. TP-A03 also belongs in the manipulation list: membership is many-to-many and preserves the same underlying item. More involved items such as TP-C16 or TP-G27 remain in the problem bank. The lesson box labels themselves are unchanged.

The public exercise list endpoints resolve registry codes against published records at request time. Missing or unpublished entries are omitted; no database migration is needed. Existing problem IDs and direct links remain valid, including references in exams, lessons and personal lists. The problem listing, facets and topic counts exclude the registry's exercise codes. Old curated list links remain accessible; external resources and personal lists keep their existing behavior.

When adding or reviewing content, assess the actual statement in the context of the taught methods, rather than inferring its classification from a level, a title or a lesson box. Add its code to every appropriate ordered topic list in `additional`, or to a lesson's exercise box when it belongs there. A code in any exercise list is excluded from the problem listing. Review the boundary cases and update the tests when the editorial policy changes. Content outside the registry, including newly published submissions and external material, is not automatically classified and needs editorial review.
